# CivicFix AI – Security & Privacy Specifications

## 1. Authentication & Session Management
- **Password Hashing:** Passwords are salted and hashed using `bcryptjs` with 10 salt rounds. Plaintext passwords are never logged, stored, or returned in database queries.
- **JWT Authorization:** Stateless Bearer tokens signed with a 256-bit secret key and standard expiration (7 days). Tokens are verified per request using Express middleware.

## 2. Role-Based Access Control (RBAC)
Every sensitive operational route is strictly gated by role middleware:
- **Citizen:** May only report complaints, edit their own active tickets, and submit satisfaction ratings on tickets they created.
- **Officer:** May view assigned complaints, mutate operational statuses, and upload field resolution proof. Cannot access global user records or delete tickets.
- **Admin:** Holds full oversight across departments, officers, priority overrides, and CSV audit reports.

## 3. Citizen Privacy & Public Data Sanitization
- On the public transparency map (`/api/public/transparency`), citizen names, phone numbers, email addresses, and residential markers are completely stripped from JSON serialization.
- Map markers indicate only the location of the civic defect itself (e.g. road pothole or leaking pipe), preserving citizen anonymity.

## 4. Responsible AI & Computer Vision Guardrails
- **Human Identity Redaction:** Prompts explicitly prohibit Gemini from tagging, identifying, or extracting names, facial features, or license plates from uploaded photographs.
- **Structural Integrity Disclaimer:** AI visual assessments are labeled as advisory damage indicators rather than certified structural safety reports.
- **Citizen Autonomy:** All suggestions generated by AI (category, title, priority) are non-binding and completely editable by citizens before submission.

## 5. File Upload Protection
- **Format Whitelist:** Only `image/jpeg`, `image/jpg`, `image/png`, and `image/webp` MIME types are permitted. Executables, scripts, and non-image binaries are rejected by Multer file filters.
- **Size Limitation:** Maximum upload size is strictly capped at 10 MB per file.
- **Filename Sanitization:** Uploaded files are renamed using cryptographically pseudorandom suffixes (`civicfix-[timestamp]-[random].[ext]`) to prevent path traversal vulnerabilities.

## 6. HTTP & API Hardening
- **Helmet:** Enables HTTP security headers including X-Content-Type-Options, X-Frame-Options, Strict-Transport-Security, and Referrer-Policy.
- **CORS:** Restricted to approved frontend origins (`http://localhost:5173` and deployed client domains).
- **Rate Limiting:** Protects `/api` endpoints against automated brute-force attempts with a window of 300 requests per 15-minute interval per IP.
